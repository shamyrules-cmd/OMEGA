# Pac Man Field — Mini

A small, self-contained maze-chase game prototype made with HTML, CSS, and JavaScript.

## How to play
- Open `index.html` in a modern web browser.
- Click **Start / Restart**.
- Move with the arrow keys or WASD.
- Collect the dots and avoid the ghosts before the three-minute timer ends.

## Notes
- No external libraries or assets are required.
- This is a fresh prototype inspired by the original Pac Man Field project.
